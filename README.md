# SIQ Pack Editor

Локальный редактор пакетов SIGame. Он не отправляет пакеты на сервер: браузер читает `.siq` как ZIP-архив и скачивает итоговый файл на компьютер.

## Запуск

```powershell
npm install
npm run dev
```

Откройте адрес, который выведет Vite (обычно `http://localhost:5173`). Для сборки статической версии используйте `npm run build`; готовые файлы будут в `dist`.

## Что реализовано

- Отдающий пакет только просматривается.
- Принимающий пакет можно открыть или создать с 3 раундами по 5 пустых тем.
- Вопросы, темы и раунды копируются из отдающего в принимающий.
- Вместе с вопросами копируются связанные изображения, аудио и видео; при совпадении разных файлов их имена безопасно меняются.
- Есть предпросмотр медиа, редактирование текстового вопроса/первого правильного ответа в принимающем паке, перенос вопроса в другую тему и экспорт `.siq`.
- Игровые типы вопросов (обычный, без риска, кот в мешке, кот с открытой ценой, ставка, ва-банк, для всех, аукцион) видны тегами в дереве и меняются в редакторе принимающего пака.
- Типы ответа: текстовый, выбор варианта и точка на изображении (координаты `x, y, аспект` + допуск `answerDeviation`). В предпросмотре точка отмечается кружком на картинке вопроса, а в редакторе её можно поставить кликом по изображению.
- Поддерживаются пакеты SIQ4 (старый формат `ygpackage3.0`): при открытии они автоматически конвертируются в SIQ5 в памяти (типы cat→секрет, sponsored→без риска, bagcat→кот с открытой ценой, сценарий из `<atom>` делится маркером на вопрос и ответ, аудио-атомы `voice` становятся `audio`). Медиа при копировании подтягивается из исходного архива, а внешние http-ссылки сохраняются как есть и проигрываются прямо по URL.
- Экспорт собирает ZIP с максимальным сжатием (deflate-9). Для дополнительного уменьшения готового пака без потери качества используйте `python compress_siq.py <pack.siq>` — уберёт неиспользуемые файлы, продубликаты и пересоберёт PNG (пиксели проверяются на идентичность). Если этого мало, есть режим **с потерями**: `python compress_siq.py <pack.siq> --transcode [--video-crf 29] [--image-quality 85] [--ssim-min 0.98]` — видео перекодируется в H.264, JPEG пересжимается; перекодированное видео принимается только если оно меньше исходного и SSIM ≥ порога (иначе файл остаётся нетронутым), mp3 не перекодируются.
